# L2M v0.1.2

See an agent call a tool before you add a key, safer webhook replies, and a smoother first hour.

## Install or upgrade

```bash
curl -fsSL https://lsquarem.com/install.sh | sh
```

Already running the quickstart? Set `L2M_VERSION=v0.1.2` (or keep `latest`), then
`docker compose pull && docker compose up -d`. Details: https://lsquarem.com/docs/getting-started/install

Images: `ghcr.io/tensorgreed/l2m:v0.1.2` (API), `ghcr.io/tensorgreed/l2m-web:v0.1.2` (studio) and
`ghcr.io/tensorgreed/l2m-ner:v0.1.2` (optional add-on), mirrored on Docker Hub as
`lsquarem/l2m`, `lsquarem/l2m-web` and `lsquarem/l2m-ner`. Helm chart: `ops/helm/l2m`.

## Upgrade note

**Webhook replies no longer include the run's context.** A workflow with no Output node that ended on a pass-through
step (Switch, If, Filter) answered `/webhook`, `/webhook-test` and the public Chat trigger with the run's variables,
system prompt and provider address. Replies now carry only the workflow's data, and run data keeps everything. If you
expose such workflows, upgrade.

## Highlights

**An agent calls a tool with no key.** With tools attached, the built-in Echo test model makes one clearly labelled
demo call to a read-only tool and answers with the result, so the run tape, tool trace and approvals show up before
you pick a real model. Try the **Agent that calls a tool** starter, or the new **Chat agent** card on Home.

**What you run is what you see.** The editor no longer sends a hidden sample prompt. **Input** next to Run holds the
prompt for workflows that read one, and LLM Call has its own Prompt field.

**A smoother first hour.**
- Example values show as hints instead of being saved as settings.
- A node added after another goes into its path instead of starting a parallel branch.
- Run data marks a `{{ }}` that had no value.
- A RAG step with no knowledge base asks you to pick one instead of answering from nothing.

**Check audit bundles with Docker.** `l2m audit verify` now ships in the API image:

```bash
docker run --rm -v "$PWD:/work:ro" -w /work ghcr.io/tensorgreed/l2m:v0.1.2 \
  l2m audit verify l2m-audit-<id>.zip --public-key audit-key.pub.pem
```

**Also:**
- Progress streams live through the quickstart's proxy.
- Average latency on the usage page leaves out approval waits.
- New guides: sending traces to Langfuse, Arize Phoenix and LangSmith, and the providers you can reach through the
  OpenAI-compatible adapter.

**Behaviour changes:**
- New and imported workflows get typed Set values: `"12"` becomes `12` when the type is Auto.
- The seeded knowledge-base templates show as unfinished until you pick a knowledge base.
