# L2M v0.1.1

Agents that talk to other agents, and your own L2M on a cloud host in a few clicks.

## Install or upgrade

```bash
curl -fsSL https://lsquarem.com/install.sh | sh
```

Already running the quickstart? Set `L2M_VERSION=v0.1.1` (or keep `latest`), then
`docker compose pull && docker compose up -d`. Details: https://lsquarem.com/docs/getting-started/install

Images: `ghcr.io/tensorgreed/l2m:v0.1.1` (API), `ghcr.io/tensorgreed/l2m-web:v0.1.1` (studio) and
`ghcr.io/tensorgreed/l2m-ner:v0.1.1` (optional add-on), mirrored on Docker Hub as
`lsquarem/l2m`, `lsquarem/l2m-web` and `lsquarem/l2m-ner`. Helm chart: `ops/helm/l2m`.

## Highlights

**A2A agents, both ways.** MCP for tools, A2A for agents, one governed runtime.
- **Expose as A2A Agent**: publish a workflow as an Agent2Agent agent (A2A 1.0; 0.3 clients answered too), with an
  Agent Card and a JSON-RPC endpoint for sending messages, streaming progress, reading and canceling tasks. Each task
  is a normal production run, so budgets, approvals and the run history apply. Sign callers in with an L2M API key.
- **A2A Agent** node: call a remote agent as a workflow step, or attach it to a Supervisor as a worker. Its token is
  a stored secret, outbound address rules apply, and worker calls ask for approval unless marked read-only.
- Guide: https://lsquarem.com/docs/runtime/a2a-agents

**Deploy to a cloud host.** Deploy buttons for Render and DigitalOcean App Platform create the studio, the API and a
Postgres database in your own account. The studio image takes `L2M_API_UPSTREAM` for hosts whose services have other
names. Guide: https://lsquarem.com/docs/getting-started/deploy-to-a-cloud-host

**VS Code extension in the stores.** Install **L2M Agent** from the
[VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=l2m.vscode-l2m-agent) or
[Open VSX](https://open-vsx.org/extension/l2m/vscode-l2m-agent).

Every image is signed with a keyless release identity and carries CycloneDX SBOMs and build provenance; the GitHub
Release has the SBOMs, the image digests and `SHA256SUMS`. How to check them:
https://lsquarem.com/docs/operations/verify-a-release
